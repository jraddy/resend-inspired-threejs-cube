# Security policy

## Supported version

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Contact the maintainer privately through [LinkedIn](https://www.linkedin.com/in/dariosimic-de) and include a concise description, reproduction steps and potential impact. Do not include credentials or sensitive personal data.

This repository is a static browser demonstration. It does not collect user data, provide authentication or run an application backend.
