# Contributing

Focused fixes and improvements are welcome.

1. Open an issue before substantial visual or architectural changes.
2. Keep the project framework-free and avoid runtime CDN dependencies.
3. Preserve reduced-motion, static fallback and cleanup behavior.
4. Do not add Resend logos, copied brand assets or unlicensed tutorial code.
5. Run `npm run check` before opening a pull request.

Pull requests should explain the user-visible change, include before/after screenshots for visual work and call out any accessibility or performance effect.
